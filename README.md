Kerala Heritage & Dying Arts 🪔
Bringing Kerala's Timeless Traditions into the Digital Future

Kerala Heritage & Dying Arts is an interactive digital heritage website dedicated to preserving, celebrating, and promoting Kerala's traditional art forms, folk performances, handicrafts, and cultural traditions.

The project combines cinematic storytelling, interactive experiences, and educational content to make Kerala's rich cultural heritage accessible to younger generations.

🌟 Features
🎭 Traditional Art Forms

Discover Kerala's traditional art forms, including:

Theyyam
Kathakali
Kalaripayattu
Mohiniyattam
Tholpavakoothu
Padayani
📖 Interactive Storytelling

Explore Kerala's cultural heritage through immersive visuals, scrolling animations, and engaging stories.

🎨 Kathakali Face Customizer

Explore Kathakali-inspired makeup styles and learn about their traditional characteristics.

🧩 Traditional Mask Matching Game

Play a memory-matching game featuring cultural motifs while learning about Kerala's artistic traditions.

📜 Interactive Historical Timeline

Discover the history and development of Kerala's traditional arts through an interactive timeline.

🖼️ Traditional Crafts Gallery

Explore traditional crafts, materials, techniques, and artisan traditions.

📝 Cultural Quiz

Test your knowledge with two questions about Kerala's cultural heritage. Submit your answers to see your final score.

🚀 Getting Started
Prerequisites

Install Node.js and npm if they are not already installed.

Installation
Clone the repository:
bash
git clone YOUR_GITHUB_REPOSITORY_URL

Navigate into the project directory:
bash
cd kerala-heritage-dying-arts

Install dependencies:
bash
npm install

Start the development server using the script configured in package.json:
bash
npm run dev

Open the local URL displayed in your terminal.
